# Tarot Reading: notes for Claude

@INTERFACE.md

- Static site served by legacy GitHub Pages from `master` root: keep index.html at the root, relative URLs, no build step.
  Keep `<script>window.APP_STATIC = true;</script>` in index.html: the local app (`python run_web.py`, port 8238) swaps it.
- The local app (`web/`) ports static/engine.js to Python: after changing the shuffle/draw rules, change both and run
  `node tools/make_engine_fixture.mjs` (the fixture both sides are tested against). Journal data goes to `data/` (git-ignored).
- Card texts come only from Waite (static/waite_pkt.js, generated by tools/extract_waite.py); do not add meanings by hand.
- Tests: `node --test tests/*.test.mjs`, `python -m pytest -q tests` and `python tests/smoke_test.py` (`--base URL` for the app).
- Keep every file under 500 lines; update INTERFACE.md and SESSION_LOG.md with structural changes.
- Card art is generated: edit tools/deck/*.mjs and run `node tools/make_deck.mjs`, never edit cards/*.svg by hand.
